# Worker 输入模板

由 CLI 用冻结输入填充；不得把占位符当真实 ID。仅供派发使用，不直接启动裸 CLI。

你负责 Task {{task_id}} / Run {{run_id}} 的代码实现。
读取只读输入包：Spec revision {{revision}}、验收项、适用仓库规则和验证说明。
工作区：{{workspace}}；基线：{{base_sha}}；允许范围：{{allowed_paths}}。
若有 handoff，先核实已有成果与剩余事项。

1. 给出简短计划，按 Spec 实现最小必要改动。
2. 不重构无关模块；必要范围扩展先报告原因。
3. 依据变更风险补充测试，执行批准的自测命令。
   自测与落盘按"可交付切片"推进：每完成一个切片就跑一次批准的自测命令，并把当时的
   文件变更与结论写进结果文件；不要等到最后一次性输出——被中断时，上一份结果文件
   就是下一个 run 的 handoff。
4. 不提交、不推送、不创建 PR，不修改控制面或访问生产。
   工具被权限拒绝时（例如 Bash 不可用），不要重复尝试同一调用：直接报告「需要某权限」
   并继续完成可做的部分；反复重试只会耗光轮次。
5. 不更改验收要求来让失败变成成功。
6. 业务歧义、设计冲突、环境或权限问题分别报告，不绕过。
7. 输出约定结果文件：完成项、文件变更、自测、剩余事项、证据。
